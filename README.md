```
Palpite nos jogos da copa 2026 com simulação Monte Carlo
========================================================

Cálculo feito com base nos jogos anteriores do campeonato.

Para usar, crie a pasta dados/ com jogos.csv -> registre todos os jogos do
campeonato até o momento, cada gol de cada jogo é importante para a simulação:

placar-copa-2026/
├── dados/
|   └── jogos.csv
├── cli.py
└── formula.py

exemplo de csv:

[...]
026-07-04,Canada,0,3,Marrocos
2026-07-04,Paraguai,0,1,Franca
2026-07-05,Brasil,1,2,Noruega

Tô puto, te vira pra adicionar os anteriores.

```

```
05-07-2026 20h00
-----------------

As maiores chances do Brasil eram um 2x1, se o arrombado não tivesse perdido o pênalti. 
Talvez os jogadores estivessem menos desanimados.

Na verdade, o palpite menos provável poderia se concretizar se a porra da seleção
tivesse só um pouco de senso de urgência (3x2 - 1,8%) ou um empate (2x2) e 3x2 nos pênaltis.

Acho que é inegável que todos os possíveis resultados mais prováveis poderiam ter
se concretizado tranquilamente. Mas as variáveis são muitas, assim como o arrombado
ter perdido a porra do pênalti, e os outros putos não terem perdido tantos gols.
```
